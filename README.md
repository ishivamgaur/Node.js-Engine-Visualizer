# Node.js Engine Visualizer

A fully interactive, client-side web application designed to mechanically simulate and visually render the internal execution flow of the **JavaScript V8 Engine** and the **Node.js Runtime Environment**. 

Instead of treating JavaScript as a "black box," this tool acts as an x-ray—parsing raw code into an Abstract Syntax Tree (AST) and exposing the exact, step-by-step lifecycles of the Call Stack, Event Loop, Task Queues, and Execution Memory Contexts entirely within your browser.

---

## 🚀 Key Learning Features

* 🧠 **Execution Contexts & Memory:** Watch the exact moment variables are hoisted. Visualize the Temporal Dead Zone (TDZ) for `let` and `const`, and see lexical scopes (closures) build and destroy themselves in real-time.
* 🔄 **The Interactive Event Loop:** See exactly how the Call Stack offloads asynchronous Web/Node APIs (like `setTimeout`) and how the Event Loop accurately prioritizes the Microtask Queue (Promises) over the Macrotask Queue.
* ⚡ **Simulated Concurrency:** Test load-handling capabilities by simulating parallel API request processing to visually understand JavaScript's single-threaded, non-blocking asynchronous architecture.

## 🏗 Architecture & Internal Flow

The Visualizer functions as a complete simulation engine, strictly separating the mechanical execution logic from the visual rendering dashboard, while running 100% locally in the client environment (no backend required).

### 1. The Simulation Engine (AST Interpreter)
When you click "Run", the raw string of JavaScript is analyzed by the local engine (`client/src/engine/interpreter.js`). Here is the step-by-step pipeline:

1. **AST Tokenization:** The `acorn` library parses your JavaScript and maps it into an Abstract Syntax Tree (AST).
2. **Environment Initialization (Hoisting):** Before running line 1, the engine simulates the Global Execution Context and Memory Creation Phase. It traverses the AST, fully hoisting `function` definitions to memory and allocating `var` declarations to `undefined`. It registers `let` and `const` variables as uninitialized (triggering the TDZ).
3. **Execution Modeling:** An internal recursive evaluator walks the AST step-by-step. 
   - It pushes execution frames to a virtual Call Stack.
   - It delegates asynchronous callbacks (timers, Promises) to virtual Web APIs and Task Queues.
   - It actively mutates lexical scopes, creating hierarchically linked environment Maps (handling Closures properly via memory pointers).
4. **Timeline Generation:** At every single logical step (pushing to a stack, modifying a variable, draining a queue), the engine records a giant JSON "snapshot" of the *entire* system state. This massive chronological array of snapshots is generated instantly without network latency.

### 2. The Visualizer Dashboard
The React client acts as a visual debugger that consumes the JSON timeline generated by the simulation engine (`client/src/hooks/useVisualizerState.js`):

1. **State Injection:** It maps the rigid snapshot array to fluid UI states across various modular components (`EventLoop`, `CallStack`, `ExecutionContexts`, `TaskQueues`).
2. **Interactive Playback Engine:** A dedicated `useEffect` timer loop processes the timeline array frame-by-frame, applying the exact state of that millisecond to the React dashboard. Users can pause, rewind, change speed, or step-through the timeline manually.
3. **Synchronized Layout:** The UI highlights executing code lines in the Monaco editor simultaneously with their corresponding mechanical impacts on memory, stacks, and queues—rendering a cohesive, full-system animation.

## 🏃 Getting Started (Local Development)

The visualizer has been architected as a complete Static Single-Page Application (SPA), removing the need for a backend node server.

To run the visualizer locally:

```bash
npm run install-all
npm run dev
```

The Visualizer will be immediately accessible at `http://localhost:5173`.
